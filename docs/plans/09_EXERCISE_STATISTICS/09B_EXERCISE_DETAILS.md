# Plan 09B — 动作详情及趋势图

> 点击动作进入详情，查看适合其记录语义的概览和一张可交互的趋势图；编辑拥有独立地址。

## 1. Goal

把单动作统计整合进动作详情，并保持历史统计链接和编辑路径可用。

## 2. Entry Criteria

- Plan 09A 已实现并通过人工验收。
- [总体设计](DESIGN.md)已审核；其 §6 提及的上游页面归属差异已由产品确认并按 `AGENTS.md` 处理。
- 现有统计服务、纯派生计算与原始训练记录查询可用。

## 3. Scope

- `/exercises/:exerciseId` 为动作详情；`/exercises/:exerciseId/edit` 为编辑表单。
- 顶部动作信息与编辑入口；中部按 LoadMode/RecordSchema 适配的统计概览；底部一张趋势图。
- 最近 7 天、最近 30 天、完整历史与适用指标切换；普通外部负重默认“月 + 重量”。
- 旧 `/statistics/exercises/:exerciseId` 地址兼容，归档动作历史仍可进入。
- 复用并扩展 Domain/Application 的统计派生；不修改训练原始值和数据库版本。

## 4. Tasks

### 09B-A — 路由、详情和编辑

- [x] 将现有编辑表单挂到独立 `/edit` 路由，详情页只读展示名称、身体部位、记录方式、归档状态及右上角编辑入口。
- [x] 保持编辑加载、校验、保存、错误提示和历史 Schema 语义；编辑成功回对应详情，失败仍在表单。
- [x] 列表行、归档视图的动作链接进入详情；新建仍按 09A 返回列表。
- [x] 旧统计 URL 按 exerciseId 跳转新详情，直接访问/刷新/浏览器历史可用；无效 ID 给出可返回的空状态，不无限加载。

### 09B-B — 单动作派生指标

- [x] 在 Domain/Application 层扩展“累计组数、最大有效重量及对应次数、最佳估算 1RM”等详情 DTO，继续按 exerciseId 从原始记录计算。
- [x] `EXTERNAL` 且启用重量和次数时沿用 Epley；同最高重量的次数和日期按总体设计的规则确定。
- [x] `BODYWEIGHT_PLUS`、`ASSISTANCE`、纯次数、有氧及可选字段缺失时展示适用指标；辅助重量说明方向，不计算 1RM。
- [x] 归档、改名、重复 Block、同日多 Session 和历史编辑/删除后重新查询均保持正确。

### 09B-C — 一张可交互趋势图

- [x] 在统计派生层实现周/月/全部筛选与按日/周/月周期聚合，不为无数据日期补 0；周期极值规则见总体设计 §4。
- [x] 普通外部负重支持“重量 / 估算 1RM”，默认“月 + 重量”；其他类型只提供有效指标。
- [x] 复用或改进 `TrendChart`，让每个有效点在触摸、鼠标和键盘下显示日期/区间及数值；处理空数据、单点、多点和范围/指标切换后的选中状态。
- [x] 更新原单动作统计及路由 E2E，不删除对已归档历史和统计正确性的覆盖。

## 5. Acceptance Criteria

- 点击任意未归档或归档动作进入详情；编辑入口到 `/edit`，保存后返回详情，原表单功能无损。
- 外部负重动作显示真实累计组数、最大训练重量对应次数、最佳 Epley 1RM；默认月/重量，切换后数值和日期正确。
- 周为最近 7 天、月为最近 30 天、全部为完整历史；同日多场合并，长跨度按自然周期汇总，无记录日期不产生点。
- 辅助重量、自重、纯次数、有氧的指标和图表语义正确；无意义的 1RM 不出现。
- 图表在 320–430px 无横向溢出，触摸/键盘可读点值；零训练动作有明确空状态。
- 旧统计链接、改名及归档后的链接和刷新仍可查看正确动作；原始数据和 schema version 未改变。

## 6. Required Test Scenarios

- 领域单测：同最高重量多次的 reps 选取、Epley 最佳值、无效/缺失负重、同日多 Session、周/月边界、跨年、全部跨度分桶、无数据不补零。
- 服务测试：按 ID 查询、改名/归档、历史训练编辑/删除后刷新；错误 ID 状态。
- E2E：列表→详情→编辑→详情，旧统计 URL 跳转，浏览器后退与刷新；普通负重的范围/指标交互及点 tooltip；自重、辅助、纯次数和有氧的条件展示。
- 回归 09A 的新建返回、分类搜索、归档管理和训练 Picker；手机 320/390/430px 验收。

## 7. Out of Scope

- 删除统计首页的趋势卡和动作列表（留给 09C）。
- 新图表依赖、统计持久化、训练过程中新建动作或全站视觉重设计。
- 修改历史训练原始数据或 IndexedDB schema version。
