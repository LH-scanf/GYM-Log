# Plan 09C — 统计首页精简与整体回归

> 统计首页只呈现总体训练情况，单动作表现从动作详情查看。

## 1. Goal

移除统计首页重复的动作内容，收口 Plan 09 的导航、统计和移动端回归。

## 2. Entry Criteria

- Plan 09A 和 09B 已分别通过人工验收；动作详情与旧统计 URL 均可用。
- 单动作统计从动作列表和归档视图可达，[总体设计](DESIGN.md) §6 的页面归属差异已处理。

## 3. Scope

- 统计首页保留今年/本月训练次数与时长、年度热力图、年份切换及按日期查看训练。
- 移除首页单动作趋势卡、动作统计搜索与长列表及其专属状态/调用。
- 整理已不用的 UI 代码和断言，完成动作、统计、训练 Picker、导航的整体回归。

## 4. Tasks

### 09C-A — 精简统计首页

- [x] 移除 `TrendCard`、选择动作 Sheet、动作搜索与长列表，不影响四张指标卡和热力图。
- [x] 保留选日期→当天多条训练列表→训练详情的流程、年份选择和空状态。
- [x] 清理仅供旧首页使用的组件/服务调用；保留 09B 仍使用的统计模块和旧 URL 兼容。

### 09C-B — 回归与视觉验收

- [x] 更新统计首页 E2E：四指标、跨年热力图、按日查看和训练详情仍工作，重复动作入口确已消失。
- [x] 调整原趋势卡 E2E 和视觉截图，使核心趋势行为在动作详情接受同等覆盖。
- [x] 覆盖 09A/09B 的分类、搜索、新建返回、归档、编辑、旧链接和多种动作指标；检查 320、390、430px 的移动触控模拟、safe-area 样式和返回行为。
- [x] 完成 `AGENTS.md` 规定的全部标准质量门禁、自审与文档同步。

## 5. Acceptance Criteria

- 统计首页只有总体训练指标和年度热力图；页面没有单动作趋势卡、动作统计搜索或长列表。
- 年度指标以当前本地日期计算；年份选择只切换热力图；有训练日期可查看当日所有 Session 并进入详情。
- 单动作详情仍可从动作页及旧统计 URL 访问，归档动作历史仍可读。
- 动作、新建、编辑、训练 Picker、统计和主导航在手机宽度下无功能与布局回归。
- 所有标准质量门禁实际通过；无跳过测试、派生统计持久化、schema 升级或新依赖。

## 6. Required Test Scenarios

- 概览四指标含跨午夜/未填写结束时间；年度热力图含多场同日训练、无训练日期和年份切换。
- 点击热力图有训练日→当日训练列表→训练详情；刷新和后退可用。
- 统计首页确认无趋势卡、动作搜索和长列表；动作详情趋势仍可用。
- 320/390/430px 截图/交互复查：统计、动作列表/详情/编辑、归档及训练 Picker；全量 E2E 回归。

## 7. Out of Scope

- 新统计指标、最近进步算法、训练流程改造或全站视觉重设计。
- 删除单动作统计能力或旧统计链接；修改历史训练数据和数据库版本。
