# Plan 09A — 动作管理及新建流程优化

> 动作可按身体部位浏览和全局搜索；新建成功回到列表，归档管理保留在二级入口。

## 1. Goal

优化动作发现与新建后的返回路径，同时保持现有编辑和动作族管理能力可用。

## 2. Entry Criteria

- Plan 08 已发布；[总体设计](DESIGN.md)已审核。
- `Exercise.category`、动作族、星标、归档服务及现有列表均可用。
- 从 `master` 基线建立独立功能分支；本阶段不依赖 09B/09C。

## 3. Scope

- 动作列表顶部为横向可滚动的“全部 / 胸 / 背 / 肩 / 腿 / 手臂 / 核心 / 有氧 / 其他”。复用现有分类字段与文案映射。
- 移除可见排序菜单；保留稳定的默认名称排序和族内分组。
- 星标按钮仍可切换常用；已归档通过二级管理入口访问，仍可恢复或按原规则删除。
- 搜索覆盖所有未归档动作及动作族名称，不因已选分类遗漏；清空搜索恢复分类。
- 新建保存成功回动作列表“全部”视图，刷新数据后即可找到；失败留在表单并显示错误。
- 本阶段 `/exercises/:exerciseId` 继续为现有编辑表单，详情路由切换留给 09B。

## 4. Tasks

### 09A-A — 分类与搜索

- [x] 将列表筛选改为指定身体部位顺序，横向滚动、选中态和键盘可访问性符合 Design System。
- [x] 统一 `CORE` 展示文案为“核心”，同步动作表单、训练 Picker 和相关断言；不改变存储枚举值。
- [x] 搜索非空时跨所有未归档分类匹配动作名称和动作族名称；清空后恢复分类选择。
- [x] 维持 ExerciseFamily 分组、折叠及管理，未分类旧动作按现有补全/兜底规则可见。

### 09A-B — 次级管理与新建返回

- [x] 移除排序控件及对应 Sheet，保持确定性默认排序。
- [x] 将已归档动作从分类栏移到清晰的二级入口；现有 `?view=archived` 链接继续可直接访问，恢复与安全删除行为保留。
- [x] 保留星标切换，不在管理页新增“常用”分类；训练 Picker 的常用入口不变。
- [x] 新建成功导航至 `/exercises` 的“全部”状态并重载列表；新建失败保留字段、停留表单；编辑提交和现有详情地址行为暂不改变。
- [x] 更新受影响的 E2E 断言和截图基线，不删掉有效回归覆盖。

## 5. Acceptance Criteria

- 320–430px 宽度可横向滚动分类栏，整页无横向溢出，触控目标符合 Design System。
- “核心”在动作列表、表单和训练 Picker 中一致；数据库 `CORE`、动作族及历史引用不变。
- 选择“胸”后搜索一个“腿”动作能找到该动作；清空搜索后回到“胸”结果。
- 无可见排序、常用或已归档分类；星标、动作族管理、归档/恢复仍可用。
- 新建“深蹲”成功后在列表立即可见；失败时保留输入和错误提示；点击动作仍可编辑。
- `?view=archived` 直接打开、刷新和返回可正常工作。

## 6. Required Test Scenarios

- 分类八类及“全部”的顺序、滚动、选中态；缺失 category 的旧动作及用户手动分类不被覆盖。
- 跨分类搜索和动作族名称搜索；清空搜索恢复过滤。
- 星标开关、归档后默认列表隐藏、二级入口恢复、有历史引用时禁止硬删。
- 新建成功返回列表、保存失败原地保留字段；编辑行为不回归。
- 更新 `exercise-management.spec.ts`、`exercises-redesign.spec.ts` 以及训练 Picker 的“核心”文案断言；移动端 320/390/430px 验证。

## 7. Out of Scope

- 新动作详情、趋势图、路由改造和统计首页精简。
- 训练过程中新建动作入口、数据模型或 schema version 变更。
- 移除训练 Picker 的“最近/常用”入口。
